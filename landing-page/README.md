A modern, high-converting standalone landing page explaining the **Lumora + Cypher Swift Enterprise Business Development Partner Network**.

---

## 🎨 Theme & Brand Identity
* **Primary Color**: Lumora Royal Blue (`#4F75FF`) & Purple Accent (`#8B5CF6`)
* **Background**: Clean Executive Slate (`#F8FAFC` & `#FFFFFF`)
* **Typography**: Outfit (Headings) & Inter (Body)
* **Assets**: Official Lumora Starburst Logo (`assets/lumora-logo.png`)

---

## 🚀 Sections Included

1. **Top Announcement Bar**: Current active cohort and diagnostic fee highlights.
2. **Branded Navigation Bar**: Official logo, desktop nav, mobile hamburger drawer, and quick CTA.
3. **Hero Section**:
   - Compelling value proposition: *Scale Enterprise Revenue With Zero Technical Delivery Overhead*.
   - Subtitle explaining partnership role vs. technical fulfillment.
   - Dual CTAs (*Join Network* & *Watch Video*).
   - Trust proof metric cards: Entry Growth Diagnostic (`₹37,000`), 100% duplicate protection, 7-day dispute window, immutable ledger.
4. **Concept Video Explainer Section**:
   - 16:9 responsive YouTube player with glassmorphism cinema frame.
   - 3 core takeaways: Pre-Sales Co-Hosting, Zero Cold Spamming, Live Status Tracking.
   - Interactive URL bar allowing marketing teams to paste and preview any YouTube video link.
5. **How to Join the Network (3 Core Pillars)**:
   - **Pillar 1: Who to Join This Network**: Target profiles (B2B sales managers, tech consultants, fractional CXOs, industry connectors).
   - **Pillar 2: How to Join This Network**: 3-step onboarding flow (Register Profile, Sign Code of Conduct v2026.1, Lock First Lead).
   - **Pillar 3: Where to Join This Network**: Platform access channels (Mobile App, Partner Web Console, Admin Governance).
6. **Incentive & Compensation Matrix**: Breakdown of ₹37,000 diagnostic fees and 10%-15% retainer commissions.
7. **Interactive FAQ Accordion**: 5 common questions covering duplicate protection, code writing, and payouts.
8. **Final CTA Banner & Application Modal**: Full interactive modal for partner registration.
9. **Corporate Footer**: Partnership credits for Cypher Swift Infotech Pvt. Ltd. and Lumora Digital Solutions.

## 💻 How to View & Run

### Option 1: Direct File Open
Double click or open [`index.html`](index.html) directly in any web browser (Chrome, Edge, Safari, Firefox). Zero build step required!

### Option 2: Run with Local Web Server
```bash
cd landing-page
npx serve . -p 4500
```
Then visit: `http://localhost:4500`
